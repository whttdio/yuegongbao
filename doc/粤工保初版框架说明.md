# 粤工保初版框架说明

## 当前基座

- 基于现有 `springboot3` 单体后台基座
- JDK 版本：17
- 后端架构：Spring Boot 3 模块化单体
- 前端基座：`yuegongbao-ui`

## 已完成骨架

- 新增 Maven 模块：`yuegongbao-business`
- 接入启动模块：`yuegongbao-admin`
- 新增初版业务目录接口：`GET /ygb/framework/modules`

## 模块定位

`yuegongbao-business` 用于承载粤工保业务域，当前先放入业务模块目录，后续再按领域继续细分：

- 组织企业
- 人员档案
- 合同备案
- 考勤打卡
- 工资税务
- 社保工伤
- 培训考试
- 投诉工会
- 预警中心
- AI报告
- 设备物联
- 招聘服务
- 官网门户
- 文件中心

## 下一步建议

1. 落库设计：先定企业、项目、班组、工人、合同、考勤、工资六张核心主数据链路。
2. 权限接入：补菜单、权限标识、角色授权。
3. 前端接入：在 `yuegongbao-ui` 增加粤工保业务首页和模块入口。
4. 代码生成：对稳定表结构启用平台代码生成器，提高 CRUD 开发效率。
