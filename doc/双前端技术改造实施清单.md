# 双前端技术改造实施清单

## 目标定位

- 一套后台：`yuegongbao-admin` + `yuegongbao-framework` + `yuegongbao-system`
- 两个前端门户：`粤工保（ygb）`、`安责保（azb）`
- 数据不拆库、不拆接口，通过门户壳层、菜单归属和权限过滤实现双前端分流

## 配套文档

- 业务拆分总图：`doc/双前端业务模块拆解方案.md`
- 执行批次清单：`doc/双前端改造执行清单.md`
- 模块拆解执行稿：`doc/双前端按530与6.1可执行拆解清单-20260605.md`
- 研发派工执行稿：`doc/双前端研发派工与验收执行单-20260605.md`

## 当前实施原则

- 共性数据只维护一套：企业、人员、预警、AI、设备、高处作业等底座统一复用
- 差异体验放前端壳层：登录页、首页、菜单树、模块说明、驾驶舱口径按门户区分
- 权限按门户实时收敛：同一账号进入不同门户，只看到当前门户允许的菜单和按钮权限
- 模块迁移分两层推进：
  - 第一层：先做 `azb` 包装页，复用 `ygb` 业务页和统一接口
  - 第二层：再逐步把安责保高频模块改成独立页面和独立统计口径
