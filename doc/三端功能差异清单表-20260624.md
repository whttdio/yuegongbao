# 三端功能差异清单表

更新日期：2026-06-24

## 1. 适用范围

- 劳动者手机端：`yuegongbao-worker-miniapp`
- 企业手机端：`yuegongbao-enterprise-miniapp`
- 用工屏服务端：`yuegongbao-worker-screen-app`

本表以以下文档作为目标基线：

- `doc/劳动者端UniApp功能清单-页面结构图-接口清单-按APP分析说明书-20260607.md`
- `doc/tmp_530.txt` 中“从业人员端小程序功能模块”“企业端小程序功能模块设计”
- `doc/三端实施现状与回归清单-20260624.md`

差异等级说明：

- `P0`：主链缺口，直接影响上线演示、核心办理闭环或首屏体验
- `P1`：重要能力未闭环，能演示但不可稳定联调
- `P2`：优化项，主要影响体验完整度、运营配置或长期维护

## 4. 直接派工建议

如果按最小可执行方式推进，建议先按下面 4 条派工：

1. 前端A：负责劳动者端 `A2 + B1 + B2 + D1`
2. 前端B：负责企业端 `E1 + E3 + E5 + E6`
3. 前端C：负责用工屏 `F1 + F3 + F2`
4. 联调/测试：负责 `G1 + G2`，同步拉通培训、考勤、工资、审批四条接口链

## 5. 当前结论

- 三端已经完成“端形态拆分”，但还没有完成“功能闭环拆分”。
- 当前最该优先做的不是继续铺新页面，而是把 `培训/打卡/工资/审批/设备/招聘` 六条主链按三端语义收口。
- 用工屏后续必须坚持 kiosk 方向，不再继续沿用手机端菜单、个人中心和单列详情页思路。
