# YueGongBao UI PC Context

This project is the PC management console for `yuegongbao-ui`.

- Stack: Vue 3 + Vite + Element Plus
- Local entry: `npm.cmd run dev:ygb` or `npm.cmd run dev:azb`
- Default validation focus: login, portal switch, menu navigation, list filtering, form submit, detail view, dialog interaction
- Saved Kane tests should stay under `.testmuai/tests`
- Prefer PC browser flows over mobile assumptions
