# 粤工保前端管理端

## 说明

当前目录已经切换为 **Vue 3 + Vite + Element Plus** 前端工程，用于承载粤工保后台管理端。

## 技术栈

- Vue 3
- Vite
- Element Plus
- Pinia
- Vue Router 4
- Axios

## 启动命令

```bash
npm install
npm run dev
```

## 打包命令

```bash
npm run build:prod
```

## 备注

- 旧版 Vue 2 前端已备份到 `../yuegongbao-ui-vue2-backup`
- 当前默认后端代理地址为 `http://localhost:8080`
